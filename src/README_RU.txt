Приветствия Монолита (Monolith Voice Greetings) 0.1.0 от Expand
Монолитовцы здороваются с вами фразами других группировок.
Для S.T.A.L.K.E.R. Anomaly / G.A.M.M.A.

ЗАЧЕМ
Все приветствия Монолита в игре беззвучны: у ванильного голоса Монолита и у голосов
Монолита из Dux's Innumerable Characters Kit на их месте лежит пустой файл 0,2 с.
Поэтому дружественный монолитовец открывает рот и ничего не говорит.

ЧТО ДЕЛАЕТ МОД
- Монолитовцы произносят приветствие другой группировки. Группировки выбираются в MCM
  (по умолчанию: Грех и Военные).
- Каждый сталкер всегда говорит голосом одной и той же группировки.
- Монолитовцы в масках говорят через маску (игровые фразы "в маске"), остальные -
  чистым голосом.
- Без Dialog Greetings: здороваются, когда вы подходите к ним, как любые сталкеры.
- С Dialog Greetings 1.0.5+: здороваются тогда, когда это делает Dialog Greetings
  (по умолчанию только при открытии диалога), со всеми его настройками (шанс,
  перезарядка, спутники...). С Dialog Greetings 1.0.4 и более ранними: в диалоге здороваются
  только монолитовцы с ванильным голосом.
- Монолитовцы, у которых голос не монолитовский, говорят своим приветствием.

ТРЕБОВАНИЯ
- Anomaly 1.5.2+ / G.A.M.M.A. Другие моды не нужны.
- По желанию: Dialog Greetings 1.0.5+ от Expand.
- MCM (есть в GAMMA) для настроек; без MCM используются значения по умолчанию.

УСТАНОВКА (MO2)
1. Установите архив через MO2 ("Установить мод из архива") и включите его.
2. Перезапустите игру. Можно добавлять и удалять посреди прохождения.

MCM -> "Приветствия Монолита" (все настройки применяются сразу, без перезапуска)
  Приветствия Монолита              - вкл
  Чьи приветствия использовать:
    Грех                            - вкл
    Военные                         - вкл
    Одиночки, Чистое Небо, Долг,
    Свобода, Бандиты, Экологи       - выкл
  Прочее:
    Журнал отладки                  - выкл

СОВМЕСТИМОСТЬ
- Не заменяет игровые скрипты и звуковые файлы. Добавляет звуковые секции с ванильными
  файлами приветствий выбранных группировок, поэтому моды-озвучки, заменяющие эти
  файлы, тоже работают.
- Заменяет ванильный звук приветствия (meet_hello) только у сталкеров с голосом Монолита.

ПРОИЗВОДИТЕЛЬНОСТЬ
Нет работы каждый кадр: одна проверка, когда сталкер начинает фразу; чужой голос
загружается сталкеру только при его первом приветствии.
