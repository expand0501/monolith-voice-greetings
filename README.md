# Monolith Voice Greetings

A mod for **S.T.A.L.K.E.R. Anomaly G.A.M.M.A.** by Expand.

**[Download the latest version](https://github.com/expand0501/monolith-voice-greetings/releases)** · [Русский](#русский)

Every Monolith greeting in the game is a silent file, so friendly Monolith stalkers greet you with no sound.
This mod gives them the greeting lines of other factions.

## Features

- Monolith stalkers greet you with the greeting lines of the factions you pick in MCM (default: Sin and Military).
- Each stalker always keeps the same borrowed voice; masked Monolith speak through their mask.
- Without [Dialog Greetings](https://github.com/expand0501/dialog-greetings): they greet you when you walk up, as in the base game.
- With Dialog Greetings 1.0.5+: they greet you when it says so (by default when you open a dialog), with all its settings.
- No replaced game scripts or voice files, no per-frame work, safe to add or remove mid-playthrough.

## Installation (Mod Organizer 2)

1. Install the zip from [Releases](https://github.com/expand0501/monolith-voice-greetings/releases) as a new mod and enable it.
2. In game: MCM > Monolith Voice Greetings. No new game needed.

The full manual and version history are in [`src/README_EN.txt`](src/README_EN.txt) (also inside the zip).
Changes per version: [`CHANGELOG.md`](CHANGELOG.md).

## Русский

**[Скачать последнюю версию](https://github.com/expand0501/monolith-voice-greetings/releases)**

Все приветствия Монолита в игре — беззвучные файлы, поэтому дружественные монолитовцы здороваются молча.
Мод даёт им фразы приветствия других группировок.

- Монолитовцы здороваются фразами группировок, выбранных в MCM (по умолчанию: Грех и Военные).
- Каждый сталкер всегда говорит одним и тем же голосом; монолитовцы в масках говорят через маску.
- Без [Dialog Greetings](https://github.com/expand0501/dialog-greetings): здороваются, когда вы подходите, как в оригинальной игре.
- С Dialog Greetings 1.0.5+: здороваются, когда это делает он (по умолчанию при открытии диалога), со всеми его настройками.
- Не заменяет игровые скрипты и звуковые файлы, нет работы каждый кадр, можно ставить и удалять посреди прохождения.

Установка: архив из [Releases](https://github.com/expand0501/monolith-voice-greetings/releases) через MO2, затем MCM > Приветствия Монолита.
Полное описание: [`src/README_RU.txt`](src/README_RU.txt) (Windows-1251).
